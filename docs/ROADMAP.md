# Roadmap

This page lists finished work and what is planned next.

---

## ✅ Phase 1: Production readiness and Compose performance (done)

- [x] **State management**
  - Every ViewModel updates its state atomically with `_uiState.update { … }` instead of direct assignments.
  - All `UiState` classes are marked `@Immutable` so Compose can skip unchanged composables.
  - Every screen collects flows with `collectAsStateWithLifecycle()`, so work stops while the app is in the background.
- [x] **List and scroll performance**
  - Lazy list keys use stable domain IDs (`book_id`, `film_key`, `food_entry_id`, `id`) instead of list indexes, which avoids needless recomposition and scroll jank.
- [x] **Networking**
  - `NetworkClient` no longer blocks on a DataStore read for every request. Settings are cached in memory with an `AtomicReference`.
  - `HttpLoggingInterceptor` is disabled in release builds.
- [x] **Security and privacy**
  - `data_extraction_rules.xml` (Android 12+) and `full_backup_content.xml` (Android 11 and older) keep API keys and settings out of cloud backups.
  - Cleartext HTTP is allowed on purpose (`network_security_config.xml`) so the app can reach self-hosted servers on a local network, such as `http://192.168.1.50:8787`. Use HTTPS for any server reachable from the internet.
- [x] **Health Connect**
  - End-to-end Health Connect webhook support in the Cloudflare Worker, the Go backend and the Android app.
- [x] **Release checks**
  - `lintRelease` passes with no errors.
  - R8 full mode produces a release APK of about 2.5 MB.

---

## ✅ Phase 2: Adaptive layouts for tablets and foldables (done)

- [x] **Window size handling:** the app detects wide windows and switches layouts automatically.
- [x] **Adaptive navigation:** a floating bottom bar on phones, and a floating navigation rail on wide screens.
- [x] **Multi-column lists:** Books, Films and Nutrition switch to an adaptive grid (`GridCells.Adaptive(minSize = 340.dp)`) on wide screens.
- [x] **List-detail layout:** on wide screens, tapping a book, film, meal, track, health record or notification opens the details in a side pane instead of a bottom sheet.
- [x] **Collapsing app bars:** long lists hide the top app bar while scrolling (`enterAlwaysScrollBehavior`) to give more room to content.

---

## ✅ Phase 3: Material 3 Expressive consistency (done)

- [x] Shared filter controls on every list screen: search, sort, custom date picker, quick date ranges (Today, 7, 14, 30, 90 days) and result count.
- [x] Customizable stat cards on every screen: show or hide, and drag to reorder, saved per screen.
- [x] Consistent segmented lists, empty states, error banners and status badges.
- [x] In-app language switch (English and Turkish) that also applies to sheets, dialogs and menus.
- [x] New name and adaptive icon: Mozaik.

---

## 🔮 Phase 4: Integrations and new features

- [x] **Trakt.tv:** films and TV episodes (by season and episode) in the timeline and database, with a settings card for username, Client ID and film, series and rating toggles. Uses the 90-second sync cooldown with a force option.
- [x] **MDBList:** multi-source ratings (Rotten Tomatoes 🍅, RT Audience 🍿, IMDb ⭐, Metascore Ⓜ️, Letterboxd 🟢, Trakt 📺) with a 14-day cache (`mdblist_ratings_cache`) to save API quota, shown as `MediaRatingBadges` on film details.
- [x] **Simkl:** film, series and anime watch history.
- [x] **Music:** Last.fm, ListenBrainz, Stats.fm and the Web Scrobbler webhook.
- [x] **Music on the Go backend:** Last.fm, ListenBrainz, Stats.fm, the Web Scrobbler webhook, import and integration toggles on the self-hosted server, with the same API as the Worker.
- [ ] **Localized server text:** some titles generated by the server, such as health record titles, are always Turkish. Generate them in the app from the record type instead.
- [ ] **Optional critic ratings on film cards:** a setting to show IMDb, Rotten Tomatoes and Metacritic badges in the film list. Off by default to keep the list clean; always shown on the detail screen.
- [ ] **Spotify Direct API:** currently playing track and playlist sync.
- [ ] **Steam:** game library, playtime and achievements.
- [ ] **Home screen widgets:** daily calories, steps, the last film or series and recent activity, built with Jetpack Glance.
